# Physics Calc (short for calculator)

This is a C++ terminal app, that you can use to do your homework.

I made this application because I wanted to make it easier to calculate some things easier in everyday life.
I tried adding things that are actually helpful in day-to-day activities, like calculating how long will it take to get between 2 points.

I think I improved a lot since the last C++ project I made.

## Features

#### You can do the following in the app:

- Calculate velocity, density, energy and more
- even calculate your electricity bill!
- do quizes to see how smart you are in ~7 grade physics
- read very very fun facts about physics
- and the app has got your back even if you leave the Earth: you can choose on which planet are you
- export the results of calculations

## How to run

You can do it the easy way or the hard way

- ***1st method***: download the `physics_calculator.exe` from the release v1.0.0 (ONLY ON WINDOWS)

- ***2nd method***: copy the git, and compile the `main.cpp` file. It should run on any platform, as it doesn't use any platform specific features.

## How to actually use it

You can navigate the app using keys from your keyboard.

On each screen enter the number of the menu you'd like to select *(pls don't enter letters because the app will go into infinite loop)*.

Where you need to enter data for a question you can enter floating point values, just put a `.`, like this: `3.1415`.

If you export a calculation, it will get saved into `results.txt`, in the same folder as the executable file.
